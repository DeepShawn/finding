# v2.0.0 测试记录

测试日期：2026-10-07。结果数据另见 [test-results.json](test-results.json)。

## 环境与方法

Chromium **144.0.7559.96**，Debian Linux，Playwright Python，Xvfb 与 ANGLE / SwiftShader 软件 WebGL。桌面视口包含 1280×900、1440×1000；手机模拟为 390×844，另检查 844×390 横屏。

浏览器的页面检查通过 `page.set_content` 载入生产单文件构建；不是在真实 GitHub 域名访问。因 `about:blank` 不提供正常站点存储，保存 / 继续测试使用仅限测试的内存 localStorage 替身。生产代码没有该替身。另以 Python 临时 HTTP 服务核对目录版全部资源在仓库式子路径下可读取且字节一致。

截图均来自实际浏览器绘制，没有用外部概念图替代运行画面。软件 GPU 的渲染速度不代表消费设备帧率，本测试不提供 60 FPS 等性能承诺。

## 修复后复测

修复了俯视模式近距离线索被遮挡时反复调用调查的问题；路径目标现在要求可接近且无遮挡。修复新局误保存菜单机位的问题。触屏控件增加小屏 / 横屏布局判断，避免设备媒体查询仅报告鼠标时漏显摇杆。上述改动后的最终通关与触屏测试通过。

## 尚未验证，不能当作保证

没有进行 iPhone / iPad Safari、Android 真机、Firefox、实际耳机听感、蓝牙手柄、长时间低内存压力或无障碍读屏验收。没有进行跨进程真实浏览器持久化、不同源存档迁移、真实域名鼠标锁定或全屏授权验收。

没有登录用户 GitHub、创建仓库、推送文件或实际触发线上部署。随包工作流依据官方 Pages 文档及官方静态站点模板编写，具体仓库权限、组织策略和线上发布仍需在用户账户验证。

界面支持触屏并不等于所有手机上高画质均流畅。低性能设备应选择“性能优先”、2D 俯视或经典调查。浏览器不允许声音、全屏、锁定鼠标或本地存储时，相关功能可能受限。
