# 深层协议：规则与剧透说明

> 本文件包含解法思路。具体数字依赖版本、章节、强度与种子，不存在一个万能固定密码表。

## 每章必经顺序

记第 i 区的现场记录为 Lᵢ、校准残页为 Sᵢ，分析为 Aᵢ、原机关为 Bᵢ、复核为 Cᵢ。

```text
第1区：L1 → S1 → A1 → B1
第2区：L2 → 返回第1区领取S2 → C1 → 回第2区 A2 → B2
第3区：L3 → 返回第2区领取S3 → C2 → 回第3区 A3 → B3
第4区：L4 → 返回第3区领取S4 → C3 → 回第4区 A4 → B4
第5区：L5 → 返回第4区领取S5 → C4 → 回第5区 A5 → B5
终核：返回第1区领终核纸带 → 回第5区 C5 → 撤离
```

Sᵢ 在拿到 Lᵢ 后才出现，不能一开始就搜到所有回溯资料。Cᵢ 使用 Aᵢ 的分析回执和 Lᵢ₊₁ 附带的纸带；C5 使用首区最后释放的终核纸带。需到终端所在区域才能核验。

任意原始文字线索下方的「深层夹层」都可查看该区域新增记录。病院最后一处的资料入口附在离院大门记录上。调查矩阵显示已经读取的 L / S，并能免费复读。

## 九类现场分析

### 1. 时间线

所有时间差约束构成连通图。把任意一个事件设为 0，沿已知差值求出相对时间，最后排序。绝对日期不重要。生成器给各事件分配不同的真实时间，所以不会出现需要任意打破的并列。

### 2. 人员—徽章—房间

每个人分配一枚不同徽章和一个不同房间。先用锚点与循环房号关系解出每个人的房间，再根据徽章—房间表确定徽章。在输入框中同时指定两个属性。任何重号都不合格。

房号循环：深渊 01→02→03→04→01，噩梦另有 05。前进的格数按这条环计算，不是简单超过房间总数就无效。

### 3. 多层转译

先按符号字典译出数列，再按「位置顺序」重新读取，最后加相应校准数。位置从 1 开始，不能把位置编号当成实际数字。只保留个位，前导零也算一个位置。

噩梦还需要从左往右把上一位已经求得的结果加入下一位。请把原列、重排列、校准列、结果列分开记录。

### 4. 数织

每个行列提示是连续实格的段长，不是整行总数。例如 `[2 1]` 表示先有一段连续两格，然后至少一个空格，之后一段一格。所有格子必须标为 ■ 或 ×；留着未知 · 不算填完。

先用最长段找交叠格，交叉验证行与列。生成器只接受行列提示唯一确定的谜面；验证器仍直接检查连续段规则，不依赖操作顺序。

### 5. 翻灯矩阵

按下会翻转本格和上下左右邻格。每个按钮只需要考虑按或不按；两次等于不按。从第一行猜一组按法，然后第二行逐一消掉第一行仍亮的格，依次追到最后一行。

深渊 4×4 最多考虑第一行 16 种，噩梦 5×5 最多 32 种。任何能让全板熄灭的按法都通过，不要求复现生成时的按法。重置回到本轮初始灯阵；撤销最多回退最近 200 次操作。

### 6. 约束路线

路径必须同时满足：相邻四向移动、不重复、不经过禁行格、起终点正确、三个检查点依序出现、步数准确、采样和准确。起点计入采样和，不计为一步。

右下角的小数字才是采样值，中间大数字是节点编号。多条符合全部规则的路线都接受。终点不可提前进入；点击上一格或撤回按钮可后退。

### 7. 整数方程配平

每个字母是有界非负整数，全部测量式同时成立才通过。可用代入、消元或有界枚举。深渊显示每一式按当前旋钮计算出的值，噩梦去掉这个即时计算辅助。

生成矩阵由严格对角占优矩阵排列而来，因此在实数域有唯一解；已知答案本身位于允许整数范围。所有数值是游戏规则，不用于现实实验站操作。

### 8. 联动表盘

按钮会同时改变多块表盘，表盘在模 5 或模 7 下循环。把按钮按压次数视作未知量，建立模线性方程。生成器使用可逆矩阵，目标状态可达。

按钮按满一个模数次数等于没按，顺序不影响结果。重置与撤销均可使用，验证只看最后状态。

### 9. 真假证言

每个人的标记必须与他那句完整话的逻辑值一致，同时真话人数必须等于记录。只勾够人数不够。真假相同允许「同真」或「同假」；至少一人为真包含两人都真。

可先列出规定数量的真话者组合，再代回每一句话；遇到矛盾就排除。生成器枚举所有真假赋值，只保留唯一自洽解。

## 回签复核

分析完成后的回执为 6 位或 8 位数字。令纸带指定的位置重排结果为 R，校准数为 K，回签结果为 C。

深渊前两区：`C[j] = (R[j] + K[j]) mod 10`。

深渊第三区：加入上一位重排后的原数字 `R[j-1]`。

深渊第四、五区：加入上一位已经写下的结果 `C[j-1]`。

噩梦全部加入 `C[j-1]`；第四、五区还先把本位重排数字乘 3。第一位不存在前一位，按 0 处理。界面会展示完整规则，不要求背本文件。

## 获取当前种子的具体答案

深渊：使用第三层提示，或本轮游戏内的完整攻略。噩梦：本轮结束后从结局页查看攻略。

开发者也可以用无依赖 Node 脚本检查某个种子：

```bash
node tools/explain_seed.cjs hospital abyss NIGHT-0117
```

输出五道分析题的解法、分析回执和复核结果。它是随包的开发 / 剧透工具，不会在游戏正常界面自动给出答案。浏览器端公开模型也不是反作弊边界。
