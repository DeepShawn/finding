## 环境

Chromium 144.0.7559.96 / Debian GNU/Linux 13；Python Playwright；Xvfb + ANGLE SwiftShader 软件 WebGL。桌面测试视口为 1360×960 和 1440×1000；手机为 390×844 和 844×390，使用 Chromium 真实触摸事件模拟。

浏览器对本地 URL 导航受当前环境限制，故完整 UI 测试将生产离线 HTML 用 `set_content` 载入 `about:blank`。序列化和迁移检查使用 **测试专用内存 localStorage 替身**；它不进入发布源码，不是实际域名持久存储、跨浏览器/设备或跨进程保存的验收。HTTP 路径检查独立使用 Python 请求完成，不是浏览器上线测试。

## 尚未验证与实现边界

没有 iOS / Android 真机、Safari、Firefox、不同显卡驱动的兼容性或长时性能基准。没有在用户账户建立 GitHub 仓库或实际发布 Pages。音效由本地 Web Audio 合成，未做所有扬声器/耳机的主观听测。不同设备上应先调低音量并按性能切换画质。

游戏是轻量风格化三维、点击调查与平面导航，不含真实追逐 AI、多人、服务器、可信排行榜、照片级光追或无缝跨区移动。所有主机关固定可解，不做随机化防作弊承诺。
