# v4.0.0 实际验证报告

验证日期：2026-10-07。对象为本包 v4 源码与由它生成的离线 HTML，不引用 v3 历史通过记录来代替新测试。

## 结论

**纯谜题模型、两档高难度的整章依赖流程、经典模式回归、存档序列化与手机模拟布局均已通过本轮检查。** 当前环境无法提供 WebGL 2，因此本轮没有验证 3D GPU 渲染。没有真实线上部署验收或物理手机测试。

## 已执行项目

| 输入容错 | 非法格子/下标重置或过滤、种子字符过滤、草稿长度限制及 HTML 转义 |

| 模拟触控 | 正常收集第一处两份残页并提交身份题；触控操作各类控件；2D 摇杆移动；点击调查点自动走近后打开深层门禁 |

| 静态资源 | Python 临时 HTTP 服务核对相对资源在仓库式子路径下的实际响应和文件字节 |

谜面生成检查包括确定性、参考解验证、翻灯与联动表盘的实际按法、回签运算和异常状态清洗。路线、翻灯等类型允许多解，测试和游戏都不把参考答案当作唯一有效答案。这里没有宣称所有类型都是唯一解题。

## 测试方法

高难整章测试由 `DepthModel` 提供正确输入，通过实际 UI 读记录、点击控制器、提交表单、返回旧区域、保存继续和撤离；不把 `analysed`、`audits`、`solved` 直接改成完成。经典整章测试同样逐题操作。自动化利用已知答案，**不代表人类的推理能力、通关时间或难度曲线评估**。

布局测试为快速覆盖后期机关，会显式设置前置条件、门锁与已读记录。它们只验证布局和控件，不用来证明通关。真假证据保留、提示额度边界、异常存档和超时测试也使用明确的边界测试状态。

本轮检查发现并修正了 320px 手机上的八位转译符号溢出，补充了窄屏数织与路线格子的最小宽度处理。原密码窗与三视角操作手册中的固定旧扣罚文字也已更新。

## 环境限制

- Chromium 报告 **`WebGL 2 unavailable`**。即使设置软件图形参数，本环境也没有得到可用渲染器。保留的原生 3D 引擎和 25 个三维场景未做新建或重写，**不能据此宣称它们在 v4 已重新通过 GPU 验证**。
- 浏览器导航本地 HTTP URL 受环境限制，UI 测试使用 `page.set_content` 加载生产单文件至 `about:blank`。静态 HTTP 路径由独立 Python 检查验证，不是浏览器在线加载的替代验收。
- 存档测试注入测试专用的内存 localStorage 替身。它证明序列化、恢复和迁移逻辑，不证明真实站点、隐私模式、跨进程或跨设备持久性。生产包不加载该替身。
- 手机是 Chromium 触屏模拟，不是 iOS、Android 真机；没有 Safari、Firefox、GPU 帧率、电量、长期运行或音效听感验收。
- 没有代建仓库、执行实际 GitHub Actions 发布或检验真实 Pages 地址。
