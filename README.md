# 静默病院：深层协议

**THE SILENT WARD — THE DEEP PROTOCOL / v4.0.0**

> 你已经知道怎样打开门。这一次，你还得证明门后发生了什么。

五章、二十五个区域、三种视角。v4 把高难度流程改成「取证 → 回溯 → 分析 → 原机关 → 跨区复核」，而不是单纯缩短倒计时。

**默认选择「深渊推演」**。初次体验新增谜题，可以同时选择「沉浸探索」：完整高难内容，没有时间限制。经典模式仍可重玩 v3 的原流程。

## 本版新增了什么

在原有 **25 道机关**之外，新增 **25 道现场分析题、25 轮跨区回签复核**。高难度每章 **15 个完成节点**，五章合计 **75 个节点**。其中回签复核是统一规则体系下的不同种子、不同纸带与递进计算，不应理解成 75 种互不相同的玩法。

新增分析题使用九类控制器：**时间线重建、人员—徽章—房间对照、多层数码转译、数织、翻灯矩阵、约束路线、整数方程配平、模运算联动表盘、真假证言**。每个区域有主题文字和自己的参数；新开局可以生成不同谜面。

五章的空间和原有剧情保持不变：静默病院、回声地铁、雨夜孤儿院、沉没实验站、黑星天文台。**本次没有新增第六章或新的 3D 地图**，重点是现有内容的推理深度与解谜工作量。

## 立即运行

源码没有安装或构建前置步骤。在项目根目录运行：

```bash
python -m http.server 8000
```

然后打开 `http://localhost:8000`。离线版可直接打开 `dist/silent-ward-v4-standalone.html`。稳定存档建议使用固定的 HTTP / HTTPS 地址；不同域名、浏览器及本地文件地址的存档不会自动互通。

游戏运行没有 npm、外部引擎、CDN、后端、账号、广告或网络上报。所有图像、场景与音效都在本地。

## 高难度的完整闭环

每章第一处区域的文字线索内新增「深层夹层」。**原文没有被替换**，新记录放在原文下方。重要操作入口也位于原有终端上，三种视角使用同一套机关。

1. 在当前区域阅读**现场记录**。第一处的校准残页在同一资料夹；后续区域的记录会释放**上一处区域**的新残页。
2. 返回上一处区域，领取**校准残页**。新现场记录还附有旧封印的回签纸带：使用旧分析回执，在旧终端完成复核。
3. 回到当前区域，依据两份残页完成**现场分析**，解除原机关的保护盖。
4. 完成该区原本的密码、排序、电路等机关，才会开放下一处区域。
5. 五道原机关全部解除后，再回第一处资料夹领取**终核纸带**，回第五处完成最后复核。全部十五个节点完成才能撤离。

分析回执会显示在成功界面和调查矩阵内，**不是原机关的密码**。回签纸带要求按位置重排、加校准数、必要时依赖前一位数字，并逐步取个位。后几轮以及噩梦模式的运算链更长，规则会逐字说明。

区域开放后可自由返回。已完成的分析与复核不会因为后续输入错误被清空。道具与记录不被新系统消耗，没有限量纸张、随机丢线索或失败后重新搜集全部材料的设计。

## 调查矩阵、草稿与种子

游戏中的 **「调查矩阵」** 显示每个区域的分析、原锁、复核状态，指出当前缺少的记录及下一处目标。已取得的深层记录可以远程复读；核验需要回到相应区域。矩阵内提供自动保存的推理草稿，最多 6000 字符，不自动检查草稿答案。

菜单中的种子可留空随机，也可填写最多 20 位英文字母、数字或连字符。**相同版本、相同章节、相同强度、相同种子会得到相同的新增谜面**。不同强度不是同一套答案。原来 25 道基础机关维持原答案；随机化针对新增分析和复核，不针对整个 3D 场景。

存档保存种子、已读残页、推理草稿、未提交的格子与旋钮、回签输入、提示次数和回响值。继续本章沿用存档中的强度，不会因为修改菜单选择而改变进行中的谜题。

## 恐怖反馈与公平性

新增 **回响值**：完整错误提交提高回响，使用新提示略微增加回响，成功分析和回签可降低回响。跨越阈值时触发预设文字、人影或声音反馈。关闭人影惊吓后，只保留文字通知；声音也可以独立关闭。

回响不改写真线索、不破坏物品、不改变机关答案，不会额外偷偷扣时。没有追逐 AI、理智值归零死亡、随机软锁、血腥处决或快速全屏频闪。

三视角仍包括 3D 第一人称、2D 俯视探索、经典调查。WASD / 触屏摇杆移动，E 调查，1 / 2 / 3 切换视角，J 线索本，H 提示，F 手电，M 声音，Esc 暂停或关闭弹窗。WebGL 2 不可用时仍可使用 2D 与调查视角。

**资料、谜题与调查矩阵打开时仍然计时。** 设置、主动暂停和切到页面后台会暂停计时。需要长时间计算或休息，请主动暂停，或选择无时限探索。

## 结局与记录

保留十五份证词和五章总终章。高难度通关还记录深层闭环次数、噩梦通关次数及评级：

- **S+**：完成全部十五节点，带齐本章三份证词，零提示，错误不超过两次。
- **A+**：完成十五节点并带齐三份证词。
- **B+**：完成十五节点，但证词未齐。

普通通关不降低已取得的完整证据。评级没有联网排行或防作弊承诺；纯前端源码与本地存档都可以被使用者修改。

深渊在游戏内可查看本轮种子的完整攻略；噩梦进行中不开放内置完整攻略，但本轮结束后可以查看。目录里的攻略随时可读，不设置 DRM。基础机关固定答案在 `docs/WALKTHROUGH.md`，新增规则与开发验证说明在 `docs/DEPTH_WALKTHROUGH.md`。

## 存档与旧版兼容

菜单 → 战役档案可以导出、导入 JSON 备份。导入会替换本浏览器里的全部五章存档及通关记录，请先备份。v4 继续使用 v3 的战役容器格式，在本章记录上增加可选的 `depth.version = 1` 数据。

没有 `depth` 字段的 v3 未完成存档按**经典调查**继续，不会中途塞入新门禁。要体验高难度，需要明确重开该章。不同章节仍独立存档；**同一章节只保存一轮未完成调查，不按强度另外开槽**。

建议升级前导出 v3 备份。v4 的新字段不保证能被旧版 v3 完整保留，不建议带着 v4 进行中存档回退到 v3。没有云端同步。

## 部署到 GitHub Pages

解压后，把 **`silent-ward-github/` 内的内容** 放到仓库根目录。根目录要直接看到 `index.html`、`src/`、`styles/`、`assets/`，并保留 `.github/` 和 `.nojekyll`。

仓库 Settings → Pages → Build and deployment → Source 选择 **GitHub Actions**，再运行随包的 **Deploy Silent Ward to GitHub Pages** 工作流。它会把 `index.html`、`.nojekyll`、`src/`、`styles/`、`assets/` 放进发布目录，不会发布攻略、测试与 `dist/`。

默认监听 `main` 分支。使用其他主分支时修改 `.github/workflows/deploy.yml`。项目资源均为相对路径，也可部署到普通静态托管服务。没有密钥、环境变量或服务器接口。

本源码包没有代你创建仓库或实际发布站点；Pages 是否可用还取决于仓库与组织权限。GitHub 官方工作流说明：

https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages
